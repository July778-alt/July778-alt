## MAIN QUEST

### AksesKita

**Public Complaint Reporting System**

AksesKita is a school project designed to provide a platform for submitting and managing public complaints.

The project includes separate user and staff experiences, report management, authentication, comments, categories, status workflows, dashboards, and location-based reporting.

**Tech Stack**

```text
Frontend       Next.js · TypeScript · React Native
Backend        Express.js · TypeScript
Database       PostgreSQL
Maps           Leaflet · OpenStreetMap
Tools          Git · GitHub · DBeaver
```

The project became one of my main opportunities to learn how a real application is structured beyond just building individual pages.
